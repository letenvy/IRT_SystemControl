# Проект управления роботами в реальном времени
Робототехническая платформа, для которой разрабатывался проект, состоит из следующих компонентов:
- 4 коллекторных (щёточных) электродвигателя постоянного тока с 4 колёсами; 
- Пластиковая рама; 
- Одноплатный компьютер Raspberry PI v.4 8Gb; 
- Плата расширения для Raspberry PI с драйвером моторов XiaoR GEEK expansion board/driver board for Raspberry Pi 3B+ 4B/5B; 
- Девятиосевой датчик положения GY-85, включающий в себя трёхосевой гироскоп ITG3205, трёхосевой акселерометр ADXL345 и трёхосевой магнитометр HMC5883L; 
- ЛНС, включающая в себя 4 внешних статических сверхширокополосных излучателя (UWB), выступающих в роли опорных точек, и 1 приёмник, являющегося навигационным модулем, установленным на роботе; 
- Литиевый аккумулятор 7.4 В с ёмкостью 5200 мАч; 
- Внешний сервер – компьютер для запуска программ управления системой робота.

## Проект реализован в многопоточной архитектуре - под каждый процесс выделяется свой поток ядра процессора.
Имеется 4 потока:
- **uwb_thread** - поток, занимающийся парсингом сообщений, приходящих от опорных точек UWB и применяющий альфа-фильтр из класса AlphaBlendFilter (файл alpha_blend.py);
- **gyro_thread** - поток, вычисляющий углы поворота Эйлера на гироскопе путём интегрирования угловых скоростей с помощью класса GyroscopeClass (файл GyroscopeClass.py);
- **hmi_thread** - поток, обрабатывающий команды пользователя, вводимые в терминал;
- **control_algorithm_thread** - поток, отвечающий за управление двигателями робота (функционал реализован в отдельном файле ControlAlgorithmRobot.py);

## Инструкция для запуска:
1. Для запуска программы управления робота нужно склонировать себе ветку "prikladniki" из данного репозитория: `git clone -b prikladniki https://github.com/letenvy/IRT_SystemControl.git`
2. Далее перейти в директорию: `cd prikladniki`
3. Внутри неё запустить основной файл robotThreads.py: `python robotThreads.py`
4. При первом запуске произойдёт калибровка гироскопа и отобразится шкала прогресса. После завершения калибровки можно спокойно пользоваться программой.
